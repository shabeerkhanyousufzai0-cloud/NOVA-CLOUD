# NOVA CLOUD

Cloud Computing Project

## Project Overview
NOVA CLOUD is a cloud-based project designed to deploy and manage four applications using containerization, Kubernetes, CI/CD, and AWS.

## Applications
1. Student Information System
2. Moodle Learning Management System
3. Company Website
4. Automated Reporting System
